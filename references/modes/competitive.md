# Competitive research mode

Compare alternatives. Competitors need not be companies: tools, methods, papers, vendors, and approaches all count.

## What this mode is for

Direct and indirect competitors, substitutes, positioning, features, pricing, audience, distribution, messaging, strengths, weaknesses, differentiation, evidence-backed gaps.

## Method

1. **Job / question** — what the user is choosing *for*. That defines the set.
2. **Set** — direct, indirect, substitutes. Include "do nothing" or incumbents when relevant.
3. **Dimensions** — only those that change the decision. Shared hygiene features do not need a 40-column matrix.
4. **Evidence per cell** — pricing page, docs, independent review, captured screenshot. Mark hearsay.
5. **Positioning and messaging** — what they claim vs what users say (if market evidence exists).
6. **Gaps** — holes relative to the job, with sources, not a wishlist.
7. **Comparison hygiene** — same version date, same geography, same plan tier.

## Sources

First-party sites, docs, changelogs, pricing, app listings, reviews, specialist roundups (as pointers). Firecrawl for page corpora. Do not build the landscape only from "best X in 2026" SEO posts.

## Output

A matrix plus a short "how to read this" note. If the user asked for a landscape narrative, still keep a table of entities.

## Pitfalls

- Assuming every competitor is a startup.
- Copying another vendor's competitor slide.
- Feature checkmarks without checking the current product.
