# Content research mode

Research of **content ecosystems**: what is being made, how it is framed, and how audiences respond — not a synonym for SEO (see keyword mode) or for visual-only work (see visual mode).

## What this mode is for

Formats, topics, hooks, narratives, recurring themes, engagement patterns, creator positioning, audience response, content gaps, platform-native behavior, temporal trends, qualitative pattern analysis.

## Method

1. **Platform and audience** — native norms differ (newsletter ≠ TikTok ≠ docs blog).
2. **Corpus** — recent examples that actually reached the audience, not only the most viral.
3. **Decompose** — format, hook, promise, proof, CTA, length, posting cadence if knowable.
4. **Patterns** — repeating themes and narratives; quote language.
5. **Response** — comments, stitches, reviews as qualitative reaction, with selection bias labeled.
6. **Gaps** — jobs or questions the corpus underserves. A gap is not "no one made a listicle yet."
7. **Time** — what changed vs what is evergreen.

## Sources

Platform search via Agent Reach when the platform is in-kit (X, Reddit, YouTube, etc.). TikTok via [../integrations/tiktok.md](../integrations/tiktok.md) when the object of study is short-form native (and doctor shows PyTok healthy). Browser for networks without a native route. Firecrawl for public articles and show notes. Do not conclude from one viral hit.

## Pitfalls

- Treating engagement as quality or as total demand.
- Mixing platforms in one statistic.
- Recommending "more authenticity" as a finding.
